# Zoid 99 SUMI-E Design System

Zoid 99 uses the canonical Sumi-Ink Command System.
This application-specific guide is adapted from the canonical Zoid Coach `DESIGN.md`.
The interface should feel like a private research ledger, not a generic analytics dashboard.

## Palette

- Ink: `#0D0A0A`
- Paper: `#FFFFFF`
- Soft paper: `#FAFAFA`
- Mist: `#F5F5F5`
- Pale rule: `#EDEDED`
- Rule: `#E0E0E0`
- Muted ink: `#545554`
- Seal: `#C23A2E`
- Seal deep: `#8F211A`
- Seal wash: `#F5E5E3`
- Healthy: `#2F3A2F`, always paired with a written label

Seal red is the only saturated accent.
It is reserved for urgent attention, approval, blocked states, and high-priority notifications.

## Typography

- Display: Times New Roman with Baskerville and Georgia fallbacks
- Body: Hiragino Mincho ProN and Yu Mincho with Times New Roman and Georgia fallbacks
- Metadata and navigation: uppercase serif labels with deliberate tracking
- Body copy: approximately 14 points with generous line height

## Surfaces and controls

- Use white paper, soft paper, mist, and one-pixel rules.
- Use zero corner radius by default.
- Use no decorative shadows.
- Prefer ruled rows, rails, and ledgers over repeated cards.
- Use black ink for primary controls and selected rows.
- Use seal red sparingly.
- Never use color without a written state.
- Make missing data visually and verbally different from zero.
- Use a Source Health Ledger with source, state, last activity, evidence, and one repair action.

## Prohibited directions

- Blue architecture or selected states
- Gradients
- Glass effects
- Warm gold
- Neon accents
- Novelty AI styling
- Rounded card grids
- Decorative shadow stacks
